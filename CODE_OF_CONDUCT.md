# Code of conduct

Skillshelf follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks aren't accepted in issues, pull requests or anywhere else the project meets.

## Reporting

To report behaviour that breaks this code, contact the maintainer privately through GitHub (the **Report a vulnerability** form on the **Security** tab also reaches them privately). Reports are kept confidential. The maintainer may remove comments, lock threads or block people who break this code.
